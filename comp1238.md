## Week 2 - Bits and Bytes
- A bit is the smallest unit of data and can be 0 or 1.
- A byte contains 8 bits.
- Computers use binary numbers to store information.
- RAM is temporary memory, while long-term storage keeps data.

## Week 3 - Structure of Text
- Markdown is used to format text with simple symbols.
- We use# for headings and ** for bold text.
- HTML uses tags to organize content on a webpage.
- Special characters may need escaping to display correctly.

## Week 4 - Text Editors
- Text editors like VS Code and Notepad are used to write and edit text.
- Ctrl + F helps us quickly find words in a document.
- Keyboard shortcuts make typing and editing faster.
- Vim is a text editor that uses commands.

## Week 5 - Command Line Interfaces
- CLI allows users to control computers by typing commands.
- The ls command shows files and folders in a directory.
- The cd command is used to move between directories.
- The mkdir command creates a new directory.
